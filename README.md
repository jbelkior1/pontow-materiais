# Ponto W · materiais

Página com o vídeo do fluxo, o mapa do sistema e os links do Ponto W, a franquia de recarga de carro
elétrico em comércios (projeto FIAP com a GoodWe).

**Link:** https://jbelkior1.github.io/pontow-materiais/

O QR que leva para a página está em [`qrcode.pdf`](qrcode.pdf) (folha A4 para imprimir), [`qrcode.png`](qrcode.png) e [`qrcode.svg`](qrcode.svg).

| Arquivo | O que é |
| --- | --- |
| `video/pontow-fluxo.mp4` | O fluxo completo em 80 segundos, narrado |
| `docs/mapa-do-sistema-resumo.pdf` | Mapa do sistema, resumo (13 páginas) |
| `docs/mapa-do-sistema.pdf` | Mapa do sistema completo (24 páginas) |

O sistema publicado fica em https://jbelkior1.github.io/gs_goodwe (código em
[jbelkior1/gs_goodwe](https://github.com/jbelkior1/gs_goodwe)). Os pontos e as recargas são de
demonstração, e todos os valores são sugeridos e ajustáveis.
